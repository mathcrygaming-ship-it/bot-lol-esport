# 🏆 BOT LOL ESPORT

Bot Discord dédié à l'esport **League of Legends**, avec un focus initial sur les **Worlds 2026**.

L'objectif est de centraliser les résultats, suivre les équipes et publier automatiquement des résumés de matchs sur Discord.

## 🎯 Objectifs

- 🏆 Suivre les Worlds 2026.
- 📊 Récupérer les résultats et les informations des matchs.
- 📰 Générer des résumés clairs et dynamiques.
- 🤖 Publier automatiquement les récapitulatifs sur Discord.
- 🔧 Développer progressivement de nouvelles fonctionnalités esport.

## 🚀 Fonctionnalités

### Disponibles au démarrage
- Connexion au serveur Discord.
- Commande `/ping` pour vérifier que le bot répond.

### Fonctionnalités prévues
- Suivi des matchs et des résultats des Worlds 2026.
- Résumés personnalisés des rencontres.
- Suivi des équipes favorites.
- Publications automatiques dans les salons Discord.
- Extension future à d'autres compétitions de League of Legends.

## 🛠️ Technologies

- Python
- discord.py
- aiohttp
- API de données esport à définir selon les sources disponibles.

## ⚙️ Configuration

Le bot utilise une variable d'environnement pour son jeton Discord :

`DISCORD_TOKEN`

**Ne publiez jamais votre jeton Discord dans le code ou dans le dépôt GitHub.**
